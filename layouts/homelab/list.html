The lightweight Kubernetes distro. Four heterogeneous nodes — x86 and a fleet of ARM machines — one control plane.

orchestration
ArgoCD

App-of-apps GitOps. Each application is one directory in one repo; new directories become new apps automatically.

delivery
Traefik

The sole ingress at the edge, with cert-manager issuing wildcard TLS behind the router. Nothing is exposed to the internet.

edge
NFS + CSI

State lives on a NAS via a CSI driver — Retain policy, per-PVC subdirs, SSD class for the latency-sensitive databases.

storage
Prometheus + Grafana

Metrics, dashboards and the alert rules that actually wake me up. Push metrics included for one-shot jobs.

observability
Beszel + Kuma

observability
Local AI

GPU nodes serve open models for inference and embeddings — private AI that never leaves the house.

ml

plumbing

On top of the stack, ~30 self-hosted services run as plain directories in the repo — no cloud subscriptions, no vendor lock-in, nothing that phones home.

UniFi Dream Router

The network itself is UniFi. The UDR runs the LAN and hands DNS upstream to AdGuard Home, which serves the *.lan wildcard — every app gets a name without touching the internet. A small syncer polls live UniFi clients and keeps per-device DNS records current, so even DHCP leases become GitOps-adjacent.

syncer source →
The NAS

Every persistent byte in the cluster lives on a self-built NAS — all PVCs served over NFS via a CSI driver with Retain policy, an SSD class for latency-sensitive databases, and an IPMI-scheduled backup drive that wakes only when it's needed.
